# Task 2 – Results

This folder contains the output files generated during the statistical summary of the GSE66625 dataset.

## Files

- `sample_statistics.csv` – Descriptive statistics for each sample.
- `control_vs_drug_comparison.csv` – Comparison of the control and drug-treated groups.
- `expression_boxplot.png` – Boxplot visualization of sample expression distributions.

These results provide a descriptive overview of the dataset and are not, by themselves, evidence of statistically significant differential expression.
